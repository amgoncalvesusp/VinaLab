# xTB runtime bundled with VinaLab 2.0

This directory distributes the official Windows x86_64 xTB 6.7.1pre runtime
from the `grimme-lab/xtb` project.

- Upstream release: https://github.com/grimme-lab/xtb/releases/tag/v6.7.1
- Runtime executable: `bin/xtb.exe`
- License: GNU Lesser General Public License, version 3 or later (LGPL-3.0-or-later)
- Full license text: `LICENSES/COPYING`

xTB remains a separate scientific component. VinaLab invokes it locally and
records its version in diagnostics; it does not alter xTB's methods or source.
