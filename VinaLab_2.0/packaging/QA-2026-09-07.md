## Remaining Gates And Boundaries

- The setup has not been installed/uninstalled in a clean Windows VM. The existing
  machine's installed application and registry were not replaced during QA.
- Offscreen Qt loses its graphics context here. Its successful window-capture
  check is not evidence for WebGL. Native graphics in the frozen application still
  needs a normal-display check; the separate source Qt viewer passed.
- Linux validation used WSL and native engines, not a frozen Linux distribution.
  A native Linux installer was not built or published.
- PM6/SQM2.20 and UFF interaction backends remain unavailable, not simulated.
  GNINA/SMINA are not execution backends in this checkout.
- Reference RMSD requires trustworthy topology and a shared coordinate frame.
  xTB reports frozen interaction energy, not binding affinity/free energy.
- Publication is performed separately from this local QA run; the GitHub Light
  release is intentionally retained as `Latest`.
